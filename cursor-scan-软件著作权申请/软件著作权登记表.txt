四、主要功能
1.  本地项目扫描：遍历目标目录，自动跳过版本库、依赖目录、二进制与超大
    文件，对全部文本文件执行静态分析。
2.  八维安全规则引擎：
    (1) 弱密码学（crypto）：MD5/SHA-1 弱哈希、DES 弱加密、ECB 模式、
        固定 IV/nonce、硬编码随机种子；
    (2) 硬编码秘密（secrets）：AWS 密钥、Slack/GitHub/Google/Stripe
        令牌、私钥块、通用密钥赋值；
    (3) 不安全反序列化（deserialization）：pickle、不安全 yaml.load、
        eval/exec 处理外部输入；
    (4) 注入（injection）：SQL 字符串拼接、shell 拼接、shell=True；
    (5) 文件权限（permissions）：chmod 0777/0666、写入 /tmp 无校验、
        世界可写目录；
    (6) 访问控制（access_control）：缺鉴权路由（Flask/FastAPI/Express）；
    (7) 依赖风险（dependencies）：requirements*.txt / package.json 中
        已知漏洞版本（离线 CVE 表）与未固定版本；
    (8) 跨站脚本（xss）：innerHTML 等 DOM 写入、React
        dangerouslySetInnerHTML、document.write、Jinja 模板关闭转义。
3.  健康度评分卡：各维度从 100 分起按严重度加权扣分（低 5 / 中 12 / 高
    20 / 严重 30），总分取各维度均分，等级 A/B/C/D/F，结果完全可解释。
4.  逐项证据输出：每条发现均给出规则号、文件:行号、代码片段、严重度、
    风险说明与修复建议（中文），保证可审计。
5.  多格式输出：text / JSON / SARIF 2.1.0。
6.  CI 门禁：--fail-on 指定严重度阈值，命中即退出码 1；用法/环境错误
    退出码 2。
7.  历史与差异：每次扫描保存 JSON 快照，支持列表与两次扫描差异视图
    （新增 / 修复 / 仍在 / 忽略 / 取消忽略）。
8.  离线 Web 仪表板：基于 Python 标准库 http.server，本地查看历史列表、
    单快照详情与对比，全程离线运行，含路径穿越防护与输出转义。
9.  忽略机制：--ignore 与 .cursor-scan.json 配置文件双来源，支持按规则
    号、文件名、相对路径及 行号 精确抑制。

五、创新点
1.  面向 AI 生成代码（vibe-code）的「安全债」定位：规则与提示文案面向
    AI 生成代码最常见的安全隐患（弱哈希、硬编码密钥、缺鉴权路由等），
    与通用 SAST 工具形成差异化。
2.  零依赖运行：核心扫描除 tree-sitter 解析库外零第三方依赖；Web 仪表板
    完全基于 Python 标准库实现，可完全离线、无网络、无 GPU（低算力守则）。
3.  AST 与正则双引擎：Python / JS / TS 使用 tree-sitter AST 精确匹配
    调用表达式，其他语言与不可解析片段回退到字符串感知的正则引擎；
    行规约器先剔除字符串字面量外的注释与文档串，显著降低误报。
4.  可解释评分体系：扣分权重与维度划分公开透明，每条发现带 file:line、
    代码片段与中文修复建议，评分结果可逐项审计。
5.  项目级跨文件规则：访问控制检测以整个项目为分析单位——先判断项目是
    否存在鉴权机制，再对未鉴权路由逐一标记，避免把无鉴权要求的纯脚本
    项目误报。
6.  快照差异语义精确：两扫描差异区分「修复」与「忽略」，被 --ignore 抑制
    的发现不会冒充已修复的问题，保证 CI 与审计报告的准确性。
