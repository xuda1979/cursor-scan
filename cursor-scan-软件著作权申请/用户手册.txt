cursor-scan 本地安全债扫描软件 V1.0
用户手册

（编写依据：GB/T 8567-2006《计算机软件文档编制规范》——《用户手册》结构）
编写：许达（中国移动研究院）

=========================================================
1  引言
=========================================================

1.1  编写目的
本手册面向 cursor-scan V1.0 的最终用户，说明软件的功能、安装、卸载、
使用方法、配置项、故障处理与常见问题，帮助个人开发者与小型团队独立
完成本地安全体检。

1.2  软件范围
cursor-scan 是一款本地静态安全扫描工具，扫描项目目录中的源代码，识别
常见「安全债」（弱密码学、硬编码秘密、不安全反序列化、注入、不安全的
文件权限、缺鉴权路由、依赖漏洞、跨站脚本），输出逐项证据、健康度评分卡
（0–100 分，A–F 等级）与修复建议，并可用作 CI 门禁。软件完全本地运行，
无需联网、无需 GPU。

1.3  术语与缩略语
  SAST        静态应用安全测试
  SARIF       Static Analysis Results Interchange Format（2.1.0）
  CVE         公共漏洞与暴露
  AST          抽象语法树
  CLI         命令行界面
  CI          持续集成
  severity    发现严重度（critical / high / medium / low）
  snapshot    扫描历史快照（JSON 文件）
  suppressed  被 --ignore 或配置文件抑制的发现（不参与评分与门禁）
  gate/door   门禁：达到阈值即非零退出的 CI 判定

1.4  参考资料
  (1) 本项目 README.md 与 SPEC.md；
  (2) GB/T 8567-2006《计算机软件文档编制规范》；
  (3) SARIF 2.1.0 规范（OASIS）。

1.5  软件运行环境
  - 操作系统：Windows 10/11、Linux（64 位）、macOS（64 位）；
  - 解释器：Python 3.10 及以上；
  - 内存：建议 ≥1 GB；磁盘：100 MB 可用空间；
  - 网络：无需网络；GPU：无需。

=========================================================
2  安装与卸载
=========================================================

2.1  安装前检查
  在终端执行「python --version」确认 Python 为 3.10+。
  Windows 请使用「py -3 --version」。

2.2  安装步骤
  方式一：源码运行（推荐，零安装）
    git clone <项目仓库地址>
    cd cursor-scan
    python -m cursorscan --version        # 直接可运行
    如需隔离环境：
    python -m venv .venv
    source .venv/bin/activate             # Windows: .venv\Scripts\activate
    pip install -r <依赖列表> 或 pip install .（见 2.3）

  方式二：pip 安装（本地包）
    python -m venv .venv
    source .venv/bin/activate             # Windows: .venv\Scripts\activate
    pip install -e .
    安装后可直接使用命令：
    cursor-scan --version

  方式三：开发模式（含测试依赖）
    pip install -e ".[dev]"
    pytest tests/ -q                      # 运行全部测试

2.3  依赖说明
  运行时依赖：tree-sitter（≥0.26）、tree-sitter-python、
  tree-sitter-javascript、tree-sitter-typescript。
  开发依赖：pytest。
  以上依赖可通过 pip 自动安装；若网络受限，请预先下载
  .whl 文件离线安装。

2.4  运行前验证
  cursor-scan --version
  预期输出：cursor-scan 1.0.0

2.5  卸载
  - 源码运行方式：直接删除项目目录即可，无系统级残留；
  - pip 方式：pip uninstall cursor-scan（同时按需删除 .venv 目录）；
  - 若有历史快照目录 ./history，可手动删除。

=========================================================
3  操作说明（按功能模块）
=========================================================

3.1  扫描项目（核心功能）
  cursor-scan <项目目录>                 # 文本报告（默认）
  cursor-scan .                         # 扫描当前目录
  输出内容：
    - 头部：软件版本、目标目录、总分/等级、扫描/跳过文件数、耗时；
    - 维度评分：八个维度各自得分与发现数；
    - 逐项发现：严重度、规则号、文件:行号、风险说明、修复建议；
    - 已忽略发现提示（如存在）。

3.2  查看逐项证据
  文本报告每条发现已含 file:line、消息与修复建议；如需含代码片段的结构化
  证据，使用 JSON 输出（见 3.4）。

3.3  评分卡与等级
  各维度从 100 分起，每条发现按严重度扣分（critical 30 / high 20 /
  medium 12 / low 5，最低记 0 分）；总分为各维度均值；等级映射
  A≥90，B≥75，C≥60，D≥40，F<40。可在文本 / JSON / SARIF / 仪表板中查看。

3.4  输出格式切换
  cursor-scan . --format json             # 机器可读 JSON 快照
  cursor-scan . --format sarif            # SARIF 2.1.0（供 IDE/流水线消费）
  cursor-scan . --format text             # 人类可读文本（默认）

3.5  历史快照管理
  每次默认扫描都会在历史目录（默认 ./history）保存 JSON 快照：
  cursor-scan --history                   # 列出全部快照（最新在前）
  cursor-scan --no-save .                 # 本次扫描不存档
  cursor-scan --history-dir <目录> .      # 指定历史目录

3.6  两次扫描差异
  cursor-scan --diff <before> <after>
  <before>/<after> 可为快照文件名或目标 slug（自动取最新匹配）。
  输出：评分变化（含 +/−）、新增/修复/仍在/忽略/取消忽略数量与逐条明细。
  被 --ignore 抑制的发现列为「忽略」，不会误报为已修复。

3.7  离线 Web 仪表板
  cursor-scan --serve                     # 默认 127.0.0.1:8080
  cursor-scan --serve --host 0.0.0.0 --port 9000
  浏览器访问后：
    - 首页：历史快照列表、评分、等级、发现数，可直接选择两次对比；
    - 快照详情：评分头、八字维度评分、逐项证据（含代码片段）、已忽略；
    - 差异页：前后评分对比与新/修复/忽略分区。
  全程离线；按 Ctrl+C 停止。

3.8  忽略误报（抑制）
  cursor-scan . --ignore 'deps.*'
  cursor-scan . --ignore 'injection.sql_concat:app.py'
  cursor-scan . --ignore 'injection.sql_concat:app.py:11'
  也可在项目根目录创建 .cursor-scan.json：
    { "ignore": ["secrets.hardcoded_key", "perms.*:tmpclean.sh"] }
  被抑制的发现不参与评分与门禁，仍显示在文本输出与 JSON 的 suppressed 中。

3.9  CI 门禁
  cursor-scan . --fail-on high            # 有 high+ 即 exit 1（默认）
  cursor-scan . --fail-on medium
  cursor-scan . --fail-on critical
  GitHub Actions 使用示例：
    - run: pip install .
    - run: cursor-scan . --fail-on high --format sarif --no-save

3.10 退出码约定
  0    扫描完成且无达到门禁阈值的发现；
  1    扫描完成且存在达到门禁阈值的发现；
  2    用法/环境错误（目录不存在、无权限等）。

=========================================================
4  配置与参数
=========================================================

4.1  命令行参数一览
  参数                默认值        说明
  path                "."           待扫描目录
  --format            text          text | json | sarif
  --fail-on           high          门禁严重度阈值
  --ignore            (无)          抑制规则，可重复
  --max-bytes         2 MiB         跳过更大的源文件
  --history-dir       ./history     历史快照目录
  --no-save           (关)          不写历史快照
  --history           (关)          列出快照
  --diff              (无)          比较两快照
  --serve             (关)          启动仪表板
  --host              127.0.0.1     仪表板监听地址
  --port              8080          仪表板监听端口
  --version           (关)          打印版本

4.2  配置文件 .cursor-scan.json
  位置：扫描目标（项目根目录）。
  格式：
    { "ignore": ["字符串模式", ...] }
  模式支持：
    - 规则号 glob：secrets.*、deps.known_vulnerable、*.py；
    - 文件名/相对路径：*.py、tests/*.py；
    - 精确组合：规则号[:文件名[:行号]]。
  CLI --ignore 与配置文件模式会合并生效。

4.3  环境变量
  本工具不依赖任何环境变量运行；如需本地 pip 离线安装可设置
  PIP 相关变量（属环境配置，非本软件行为）。

=========================================================
5  故障处理与常见问题（FAQ）
=========================================================

5.1  错误：无法识别命令 cursor-scan
  原因：未通过 pip 安装。
  解决：使用「python -m cursorscan <参数>」直接运行，或按 2.2 安装。

5.2  错误：命令返回退出码 2，提示「扫描目标不存在或不是目录」
  原因：path 参数指向了不存在的路径或普通文件。
  解决：确认目录存在；对单文件请放入目录后再扫描。

5.3  错误：提示「无权限读取目标」
  原因：运行用户对目标目录无读取权限。
  解决：调整目录权限（Linux/Mac：chmod +r、chown）；Windows 以管理员
  运行或修改 ACL。

5.4  错误：pip 安装失败（网络受限）
  解决：使用离线 wheel 包安装 tree-sitter 系列依赖；或直接源码运行
  （python -m cursorscan），本软件核心逻辑无第三方运行依赖。

5.5  Python 版本过低
  原因：Python < 3.10。
  解决：升级至 Python 3.10+；Windows 使用官网安装包并勾选「Add to PATH」。

5.6  AST 扫描某文件报 internal.scan_error
  原因：目标文件存在语法异常或极少数解析器边界情形。
  解决：该发现为低严重度提示，不影响整体结果；若确认为语法错误请先
  修复代码，或使用 --ignore 'internal.*' 抑制。

5.7  发现太多 / 想聚焦高危
  解决：使用 --fail-on critical 门禁；用 --ignore 抑制噪音规则
  （如 'deps.unpinned_package' 这类低严重度项）；查看立即统计数据
  （评级与摘要）后再深入。

5.8  web 仪表板无法启动
  原因：端口被占用。
  解决：改用 --port 9000；或 --host 127.0.0.1 检查防火墙。报错
  「无法启动仪表板」+ OSError 时同法处理。

5.9  快照 diff 报「未找到快照」
  原因：引用的 slug 无匹配或历史目录为空。
  解决：先运行 cursor-scan --history 查看可用快照；使用快照文件名
  或目标 slug 作为参数；确认 --history-dir 一致。

5.10 忽略后 diff 中仍显示为「仍在」
  原因：两快照均未将该项列入 suppressed（例如使用 --no-save 或忽略
  模式未匹配）。
  解决：确认忽略模式正确（规则号/文件/行号三级）；重新扫描后对比。

5.11 如何确保扫描完整
  说明：默认自动跳过版本库（.git）、虚拟环境、node_modules、dist 等
  目录与二进制/超大文件（>2 MiB，可用 --max-bytes 调整）。
  如需扫描被跳过项，请移除对应黑名单目录的访问权限或调整 --max-bytes。

5.12 误报与漏报处理
  - 误报（FP）：使用 --ignore 或 .cursor-scan.json 抑制；
  - 漏报（FN）：本项目为规则 + 模式的静态扫描（非完整语义/数据流
    分析），复杂跨函数数据流不在范围内；请结合人工复核修复建议。

5.13 卸载后残留
  手动删除遗留的 history 目录与 .venv；pip 卸载命令见 2.5。

5.14 获得帮助
  运行 cursor-scan --help 查看内建帮助；详细说明见 README.md。
